# CSS - Advanced

## Description
This project is part of the Holberton School / ALX **Web Front-End** curriculum. It builds directly on the previous HTML Advanced project, taking the static `Techium` homepage and styling it entirely with CSS — no CSS frameworks, no preprocessors, just plain CSS3.

In this project, we focus on:
- CSS selectors, properties, and values
- The difference between block and inline styling
- Ensuring visual consistency across browsers with a CSS reset
- Setting up and reusing CSS variables (custom properties)
- The differences between inline, embedded, and external CSS
- Building grid systems using floats
- Icon fonts vs SVG icons
- Pseudo-classes vs pseudo-elements
- Background gradients
- CSS animations and transitions
- 2D and 3D transforms
- Vendor prefixes and cross-browser support

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/<your-username>/holbertonschool-web_front_end.git
   ```
2. Move into the project directory:
   ```
   cd holbertonschool-web_front_end/CSS_advanced
   ```
3. Open `index.html` directly in a browser (Google Chrome, version 78.x, is the reference browser for this project):
   ```
   google-chrome index.html
   ```
   or simply double-click the file / open it with any browser.

## Requirements
- Allowed editors: `vi`, `vim`, `emacs`, `VSCode`, `Atom`
- All files will be interpreted on **Chrome (version 78.x)**
- All files should end with a new line
- All files should start with a comment describing the task
- A `README.md` file at the root of the project folder is mandatory
- Your code should be W3C compliant and validated using the [W3C Validator](https://validator.w3.org/)
- All images (favicon, logos, and content photos) must be stored inside an `images/` directory

## Learning Objectives
By the end of this project, you should be able to explain:
- Selectors, properties, and values
- The difference between block and inline styling
- How to ensure consistency across all browsers (CSS reset)
- How to set up CSS variables
- The differences between inline, embedded, and external CSS
- How grid systems work (with floats)
- The difference between icon webfonts and SVG icons
- The difference between pseudo-classes and pseudo-elements
- How to make background gradients
- How to animate elements in CSS
- How to transform (2D, 3D) elements
- What vendor prefixes are
