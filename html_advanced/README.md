# HTML - Advanced

## Description
This project is part of the Holberton School / ALX **Web Front-End** curriculum. It focuses on building the structure of a web page using pure HTML5 — no CSS, no styling. The goal is to practice semantic HTML and correct page structure using a fictional company called **Techium** as the theme across all pages.

In this project, we focus on:
- Creating the skeleton of an HTML5 page (doctype, `html`, `head`, `body`)
- Using semantic tags: `header`, `main`, `footer`, `article`, `nav`, `section`, `aside`
- Structuring headings in the correct hierarchical order
- Creating lists, tables, and forms in HTML
- Differentiating `div` vs `span`
- Embedding media: images (SVG, GIF, PNG, JPG), video, audio, and iframes
- Writing W3C-compliant, semantic, and well-structured HTML

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/<your-username>/holbertonschool-web_front_end.git
   ```
2. Move into the project directory:
   ```
   cd holbertonschool-web_front_end/html_advanced
   ```
3. Open any `.html` file directly in your browser to view it:
   ```
   firefox 0-index.html
   ```
   (or double-click the file / open it with any browser)

## Requirements
- All files should end with a new line
- A `README.md` file at the root of the project folder is mandatory
- Your code should be W3C compliant and validated using the [W3C Validator](https://validator.w3.org/)
- Every HTML file must start with the doctype `<!DOCTYPE html>`
- `Techium` is the company name used consistently across all pages
- No CSS/styling is required or expected in this project

## Learning Objectives
By the end of this project, you should be able to explain:
- Which guidelines to follow for HTML
- How to create the skeleton of an HTML5 page
- How to use semantic HTML tags to structure a web page
- When to use `div` vs `span`
- The semantic value of `header`, `main`, `footer`, `article`, `nav`, `section`, `aside`
- How to use headings correctly (and why hierarchy matters)
- How to create lists in HTML
- The differences between media types (SVG, GIF, PNG, JPG)
- How to structure data in a table
- How to embed video, audio, and external content (iframe) in a webpage
- How to correctly structure an HTML page overall
